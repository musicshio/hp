# デザインの判断記録

採用したものより、却下したものとその理由を残す。新しい案を出す前にここを読み、同じ理由で落ちる案は出さない。
引用符の中は shio の言葉。それ以外は Claude の要約や解釈で、解釈には「解釈:」と付ける。

新しい判断があったら、日付つきで末尾に足す。

## 2026-11-17

### 決まったこと

- サイトの目的は思想（`CONSTITUTION.md`）を伝えること。「作品はあくまで手段で、思想を伝えるのがメイン」。
- 色は紙と墨。昼は紙色の地、夜は墨色の地。差し色は朱。値は `src/lib/design-tokens.ts`。
- 昼と夜は訪問者の現地時刻で切り替える。境目は 6 時と 18 時の固定。「リアルな昼/夜の雰囲気と合わせたい」。
- 夜の黒は「もっとしっかりとした黒」。
- コピー「文脈の波にかき消されそうな実在の温かさにスポットライトを。」の「スポットライト」は「実在そのものについてみんな思弁しようね」という意味。
- トップは `main` に 2026-07 から入っていた版（霧の背景 `fog-ground.tsx`、欧文のタイトル、縦書きのコピー）を採用する。「main 採用の方がいいかな」。
  - この日の前半は、手元の `main` が古く、4 か月前のトップ（オーロラ背景）を見ながら議論していた。その画面に対して出た「music_shio とかいらない」「コピーの場所もここじゃないかも」は、いまのトップへの判断ではない。
- デザインルールは 2 行（`src/lib/design-rules.ts`）。
  1. 実在の手触りを常に意識し続ける。
  2. 置く理由を説明できない要素は入れない。
- 公開用のデザインページ `/design` を置く。色名やコンポーネント名は英語。

- 霧の背景の調整（`fog-ground.tsx`）。
  - 「画面のノイズが強すぎる」「もうちょっと抑えて」。粒子の強さを元の 4 分の 1 ほどにした。
  - 「白と黒もはっきり目がいい」。昼の紙を白く、夜の地を黒く、柱の白黒も強めた。
  - 「色がもうちょっと明るい方がいいのかなあトップとか」。昼の霧の灰色を明るくした。夜は変えていない。
  - 霧の強さはどのページでもトップと同じにする（以前はトップ以外を弱めていた）。柱はトップにだけ立つままで、これは未確認。

- 書体。
  - 全ページの書体は Zen Kaku Gothic New。「Zen Kaku Gothic New いいなあ」。欧文も和文もこれでまかなう。以前は Roboto で、和文は端末まかせだった。
  - ページの題（欧文）は Space Grotesk。「英文はもっと brutal なフォントないかなあ」「Space Grotesk いいですね h1 ではこれいいかも」。
  - トップの縦書きのコピーは Shippori Mincho のまま。
- トップから名前の文字を外す。「トップに『music_shio』の文字、いらないかもなあ」「画面下の shio もいらないなあ」。題字と、画面下の大きな「shio」を外した。「music_shio」は画面に出さないページの題としてだけ残している。

- ページの題は、どのページでも同じ位置に出す。「各ページの遷移で h1 の位置に統一性がない」。左端はヘッダーのロゴに揃え、上はヘッダーの下に一定の間をあける（`heading.tsx`）。Design の本文も同じ左端から始める。About には題がなく、まだ揃えていない。

### 却下されたもの

| 出したもの | shio の反応 | 落ちた理由 |
|---|---|---|
| 飾りの十字・点・水平線（参考画像から借りた要素） | 「意味が説明できないデザインは bullshit」「なんとなくのものなら置きたくない」 | 置く理由を説明できない |
| 朱の円＋墨の塊＋垂れ＋輪。「円＝温かさ、墨＝文脈の波」と対応づけた図像 | 「これはどういう意味？」のあと、作り直しに同意 | 解釈: 寓意画になっていた。絵にラベルを貼って解読させる作りで、ラベルの手前を味わうという思想の逆。中心がひとつある構図、照準のような輪も思想と合わない |
| 乱数で生成した点の分布（近づくと朱くなる） | 「あまりにも virtual」「actual 感出したい」 | 点が実在の何も指していない |
| 影と紙の凹凸を計算で描いた粒 | 「質の低い CG という感じ」「アクチュアル感もないし、バーチャルにしてもあまり意味を感じない」 | 解釈: 計算で物の質感を装っても、物の真似でしかない。描画の質を上げても直らない |
| 「作品そのものをトップに置く」という方向 | 「作品をトップに出すのが目的じゃない」 | 目的の取り違え。作品は手段 |
| 標語のような見出しをつけた 6 項目のルール | 「ルールが寒い」 | 解釈: 思想を標語で宣言する書き方が寒い。Claude が勝手に足した項目（「象徴にしない」「物の真似をしない」「朱は 1 画面に 1 か所まで」）も含んでいた |
| ルール「昼と夜は現地時刻で切り替える」「色は表にあるものだけ使う」 | 「いらない」「ルールに書くまでもない」 | 仕様であって判断の基準ではない |
| 色やコンポーネントに付けた一言説明（「注記や説明など、一歩引かせる文字。」など） | 「こんなの必要か？」 | 見れば分かることの言い直し |

### 確認が取れている理解

- 「説明できる」とは、なぜそこにあるかを言えること。各要素が何かの象徴になっていることではない。
- 求めている actual 感は「物としての質感」。現実の何かを指していること（データとの対応）ではない。

### まだ決まっていないこと

- 霧の背景をルール「実在の手触り」に照らしてどう扱うか。霧は計算で描いたもので、この日却下した粒の背景と同じ種類だが、shio は霧を残すことを選んだ。理由はまだ聞いていない。
- 霧は不透明で独自の紙色・墨色を持つので、`Background` の色（`design-tokens.ts`）は霧の下に隠れて見えない。揃えるかどうかは未定。
- 朱をどこに使うか。
