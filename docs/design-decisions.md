# デザインの判断記録

採用したものより、却下したものとその理由を残す。新しい案を出す前にここを読み、同じ理由で落ちる案は出さない。
引用符の中は shio の言葉。それ以外は Claude の要約や解釈で、解釈には「解釈:」と付ける。

新しい判断があったら、日付つきで末尾に足す。

## 2026-11-17

### 決まったこと

- サイトの目的は思想（`CONSTITUTION.md`）を伝えること。「作品はあくまで手段で、思想を伝えるのがメイン」。
- 色は紙と墨。昼は紙色の地、夜は墨色の地。差し色は朱。値は `src/lib/design-tokens.ts`。
- 昼と夜は訪問者の現地時刻で切り替える。境目は 6 時と 18 時の固定。「リアルな昼/夜の雰囲気と合わせたい」。
- 夜の黒は「もっとしっかりとした黒」。
- トップに「music_shio」の文字は要らない。
- コピー「文脈の波にかき消されそうな実在の温かさにスポットライトを。」は、トップからは外した。置き場所は未定（「まだ置かない」）。
  - 「スポットライト」は「実在そのものについてみんな思弁しようね」という意味。
- デザインルールは 2 行（`src/lib/design-rules.ts`）。
  1. 実在の手触りを常に意識し続ける。
  2. 置く理由を説明できない要素は入れない。
- 公開用のデザインページ `/design` を置く。色名やコンポーネント名は英語。

### 却下されたもの

| 出したもの | shio の反応 | 落ちた理由 |
|---|---|---|
| 飾りの十字・点・水平線（参考画像から借りた要素） | 「意味が説明できないデザインは bullshit」「なんとなくのものなら置きたくない」 | 置く理由を説明できない |
| 朱の円＋墨の塊＋垂れ＋輪。「円＝温かさ、墨＝文脈の波」と対応づけた図像 | 「これはどういう意味？」のあと、作り直しに同意 | 解釈: 寓意画になっていた。絵にラベルを貼って解読させる作りで、ラベルの手前を味わうという思想の逆。中心がひとつある構図、照準のような輪も思想と合わない |
| 乱数で生成した点の分布（近づくと朱くなる） | 「あまりにも virtual」「actual 感出したい」 | 点が実在の何も指していない |
| 影と紙の凹凸を計算で描いた粒 | 「質の低い CG という感じ」「アクチュアル感もないし、バーチャルにしてもあまり意味を感じない」 | 解釈: 計算で物の質感を装っても、物の真似でしかない。描画の質を上げても直らない |
| 「作品そのものをトップに置く」という方向 | 「作品をトップに出すのが目的じゃない」 | 目的の取り違え。作品は手段 |
| 標語のような見出しをつけた 6 項目のルール | 「ルールが寒い」 | 解釈: 思想を標語で宣言する書き方が寒い。Claude が勝手に足した項目（「象徴にしない」「物の真似をしない」「朱は 1 画面に 1 か所まで」）も含んでいた |
| ルール「昼と夜は現地時刻で切り替える」「色は表にあるものだけ使う」 | 「いらない」「ルールに書くまでもない」 | 仕様であって判断の基準ではない |
| 色やコンポーネントに付けた一言説明（「注記や説明など、一歩引かせる文字。」など） | 「こんなの必要か？」 | 見れば分かることの言い直し |

### 確認が取れている理解

- 「説明できる」とは、なぜそこにあるかを言えること。各要素が何かの象徴になっていることではない。
- 求めている actual 感は「物としての質感」。現実の何かを指していること（データとの対応）ではない。

### まだ決まっていないこと

- トップに何を置くか。生成した粒の背景は外したので、いまは紙色（夜は墨色）の地だけで、何も置いていない。
- 書体。いまは Roboto（本文）と Outfit（About の見出し）で、決定事項ではない。
- コピーの置き場所。
- 朱をどこに使うか。
